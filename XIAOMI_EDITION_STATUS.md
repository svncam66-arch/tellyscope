# Xiaomi Edition 0.7.0-ru.1 — предварительная сборка

Fork от Tellyscope 0.7.0 (GPL-3.0). Фирменная темно-зелёная и золотая палитра, отдельный идентификатор APK, перевод основных навигационных и критических действий, усиление защиты пакетного отключения, исходные функции ADB/мониторинга/списков GitHub и ускорения анимации.

**Ограничения:** полный перевод пока не завершён; нет автоматического удаления системных APK; нет нового двухпанельного экрана для раскрытого Huawei Mate X6; это тестовая сборка для установки и проверки.

Сборка: Actions → Tellyscope RU Xiaomi APK → скачать артефакт и распаковать APK.
