## Выполненные изменения по текущему этапу
- `DiagnosticReport`: локальный текстовый отчёт без IP/MAC/SSID/ключей ADB, пакетов и имён процессов.
- `EncryptedBackupCodec`: изолированный формат парольного шифрования с проверкой ошибочного пароля и повреждённого файла.
- `EncryptedLocalBackup`: строгий список допустимых метаданных, парольный экспорт/импорт через системный файловый диалог, явное подтверждение каждого раздела; ключи ADB по умолчанию не включаются.
- `DeviceCapabilities`: чтение сведений Android/прошивки только безопасными запросами, статус неподтверждённой совместимости.
- Флаги недоступных CPU/RAM исключают выдачу отсутствующего измерения за ноль.
- Новая отдельная зелёно-золотая адаптивная иконка TV Optimizer Pro.
- Экран расширенной диагностики: перевод и кнопка системного экспорта.
- GitHub Actions: сборки эксперимента отдельно от стабильных релизов; остановка устаревших экспериментов на том же PR.

## Дополнения 27 октября
- Исправлен UI-тест вкладок, ранее зависящий от устаревшей фиксированной высоты.
- Профиль доверия остаётся отключённым без **настоящего публичного ключа владельца**. Отдельные unit-тесты с генерируемыми ключами являются только симуляцией, а не реальными испытаниями Xiaomi.
- Подписанный профиль допускает только отключение с возвратом по точной прошивке, не содержит свободных shell-команд и не снимает критическую защиту.
- Обязательная проверка прошивки повторяется перед отключением **системного** пакета и сбрасывается при переподключении.
- Ручное восстановление копий выполняется поэтапно с предварительными копиями и откатом при ошибке. Восстановление после гибели процесса между заменами НЕ обеспечено.
- Исходный конвейер рекомендаций больше нигде не помечает действия предварительно выбранными.
- Реализован отдельный ручной экспорт ADB-идентичности в AES-256-GCM с предупреждением и особым паролем; основной архив метаданных ADB-ключи исключает. Импорт ADB-ключа и шифрование его рабочего хранилища ещё не готовы.
- Запрещена подпись stable APK в CI: локальная подпись требует `-Ptvoptimizer.localReleaseSigning=true` вне окружения CI.
- Экспериментальная APK не предлагает обновления из старых несовместимых GitHub Releases.
- До назначения публичного RSA-ключа владельцем все подписанные профили остаются недоверенными и не разрешают опасные действия.
- Подробная модель ключей профилей: [TV_OPTIMIZER_PRO_SIGNED_PROFILES_RU.md](TV_OPTIMIZER_PRO_SIGNED_PROFILES_RU.md).

## Блокирующие критерии №18, №26, №46
- Неполный русский UI, небезопасное управление системными пакетами или отсутствие любой обязательной функции блокирует stable.
- CI pass подтверждает сборку/автотесты, но не подтверждает реальную Xiaomi-совместимость.
- Промежуточные сборки — только `EXPERIMENTAL`, без гарантии сохранности данных и без публикации как stable.
- Ключ подписи финального APK создаёт и хранит владелец локально (№43-А/49-А), не добавлять его в GitHub.
